# 渲染用法

## 运行环境

使用 Node.js 20+、Playwright 和可显示中文的 Chrome/Chromium。技能目录包含 `package.json` 与锁定文件，首次可在该目录运行 `npm ci`。已有运行时依赖时，可通过 `NODE_PATH` 指向现有 `node_modules`，无需重复安装。

在 Codex 桌面环境中，若系统找不到 Node 或 Playwright，可调用可用的工作区依赖查询工具定位随附运行时；不要把该机器的绝对路径写入技能源码。脚本会探测 Playwright Chromium 与常见系统 Chrome 路径，也支持手动指定浏览器。

没有可用浏览器时，在技能目录运行 `npx playwright install chromium`。在受限环境中遵循实际工具返回的权限要求，不使用系统浏览器的用户配置或登录数据。

## 命令

把 `SKILL_DIR` 替换为技能实际目录，然后运行：

```bash
node /absolute/path/to/SKILL_DIR/scripts/render.cjs \
  --input /absolute/path/to/prompt.md \
  --title "3D 透明水箱交互模拟" \
  --output /absolute/path/to/outputs/prompt.png
```

| 参数 | 说明 |
| --- | --- |
| `--input` | 必填；UTF-8 Markdown 或纯文本文件 |
| `--title` | 必填；图片标题，原文仍完整显示 |
| `--output` | 必填；以 `.png` 结尾的输出路径 |
| `--author` | 默认 `路人甲`，支持换署名 |
| `--avatar` | 默认随附 IP；可指定本地 PNG/JPEG/WebP |
| `--browser-executable` | Chrome/Chromium 可执行文件路径 |
| `--columns` | 默认 `auto`；也可指定 1–16 栏 |
| `--scale` | 默认 `2`；可设 1–3 倍导出分辨率 |
| `--help` | 查看当前完整参数说明 |

带空格的路径和标题应正确引用。通过工具运行时，把用户文本写进输入文件，不直接拼接成 shell 命令。

## 输出与版式

`prompt.png` 是主交付；同目录还会生成自包含的 `prompt.html` 与 `prompt.check.json`。HTML 内嵌 IP 图片、样式与原始输入，方便离线查看和进一步修改，不依赖远程素材。

自动模式从短文单栏或长文多栏开始，测量实际内容高度，必要时增加栏数以得到宽大于高的画布。跨栏保持原文顺序；章节尽量保持在一起。默认单栏宽 1200 CSS 像素，多栏按内容增加宽度；2 倍导出的像素尺寸翻倍。

仅支持与提示词排版相关的 Markdown 子集：标题、有序/无序列表、行内代码、加粗、围栏代码与分隔线。其他语法按原字符显示，不抓取链接、不解释 HTML，也不执行其中的脚本。包住整段输入的 `Plain`/纯文本围栏可作为包装去除。不是通用 Markdown 排版引擎。

如需放大「提示词」标识，调整渲染器的 `labelSize` 或模板中的 `--label-size`，保持正文大小不变；重新检查页头留白和重叠。更复杂的版式直接改相应 CSS，无需重绘整张图片中的文字。

## 检查与失败处理

检查报告记录原文存储校验、可见文本块、原始列表编号、图片是否加载、页头重叠、越界、横图比例、像素尺寸、浏览器错误及外部请求。验证失败会返回非零退出码，不导出新的 PNG；已有同名 PNG 可能仍是上一次结果，应核对报告，不把旧图当作本次成功输出。

需要调整时优先修正文案输入的格式、栏数或版式，不删除正文。显式指定的栏数不足以容纳横图时，可改回自动模式或增加栏数。单个巨大代码块等特殊内容需要调整版式；脚本会停止并保留检查结果，不静默截断或拆成多张。

最终仍需查看 PNG。以原尺寸核对中文、标点、字距和 IP，以缩略图核对大号「提示词」是否醒目。超长图保留高清原图供放大阅读，不把平台压缩后的清晰度当作脚本能保证的结果。
